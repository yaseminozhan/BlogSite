# 🎵 Blog Sitesi (ASP.NET Core MVC)

Müzik, ilham, yazarlık ve paylaşım üzerine kurulu bu platform; kullanıcıların blog yazabildiği, konuları takip edebildiği ve içerik üretebildiği bir MVC tabanlı blog sitesidir. ✍️

## 🔧 Kullanılan Teknolojiler

- ASP.NET Core MVC (.NET 8)
- Entity Framework Core (Code-First)
- SQL Server
- Bootstrap 5
- Identity (Kullanıcı Yönetimi)
## 🧠 Proje Özellikleri

### 👤 Kullanıcı Sistemi
- Kayıt Ol / Giriş Yap
- Kullanıcı profili: Ad, açıklama, profil fotoğrafı
- Yazar sayfası (Kullanıcıya özel link)
- Profil düzenleme (Ad, açıklama, foto)

### 📝 Makale Yönetimi
- Makale ekleme (Başlık, içerik, süre, konular)
- Makale listeleme ve detay sayfası

### 🏠 Anasayfa Yapısı
- Giriş yapan kullanıcıya özel içerik
- Ziyaretçiye tanıtım ve yönlendirme
- Hakkımızda sayfası

### 📄 Sayfalar
- Anasayfa (üye/ziyaretçi ayrımı)
- Hakkımızda
- Konu Listesi
- Makale Ekle / Listele / Oku
- Yazar Sayfası
- Profil Düzenleme
